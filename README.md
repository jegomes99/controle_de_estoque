# 🍧 Controle de Estoque — Loja de Açaí

Sistema simples de **gestão de estoque** para uma loja de açaí.

🔗 **Ver funcionando:** https://jegomes99.github.io/controle_de_estoque/

## ✨ Funcionalidades
- Cadastrar produtos e quantidades
- Somar entrada de estoque em produtos que já existem
- Editar e remover produtos
- Dados salvos no navegador: continuam lá ao recarregar a página

## 🛠️ Tecnologias
HTML · CSS · JavaScript · localStorage

## 📚 O que pratiquei
Operações de CRUD (criar, ler, atualizar e excluir), arrays de objetos, validação de entradas e persistência com localStorage.
